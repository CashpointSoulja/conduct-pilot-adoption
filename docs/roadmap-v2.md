# v2 roadmap

Ordered by what I would want evidence for first. None of this is built.

1. **Gate overrides with a reason and an approver** (A-3, A-5): allow a documented exception for a
   non-critical test or a small cohort, recorded in the handoff.
2. **Configurable thresholds per pilot**: freshness window, activation window, minimum denominator.
3. **Multiple changes per pilot** with a shared cohort and per-change gates.
4. **Import of a dependency list from a file the customer exports** (still read-only, still no
   system access), replacing the hand-authored graph.
5. **Test result import** from a file rather than the simulated suite.
6. **Discovery tracker**: log interviews against H-1..H-5 with quotes, so a hypothesis can only move
   to "supported" with cited interviews.
7. **Shared workspaces** with real sign-in (would need a different isolation model and a privacy
   review).
